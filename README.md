# Jogo do Número Secreto

Este projeto é um pequeno jogo web em JavaScript onde o jogador tenta descobrir um número secreto dentro de um intervalo definido.

## Objetivo

Acerte o número escolhido pelo jogo antes de errar. O desafio é simples, rápido e ideal para praticar lógica de programação com JavaScript.

## Como jogar

1. Abra o arquivo `index.html` em um navegador.
2. O jogo pedirá que você insira um número dentro do intervalo permitido.
3. Se o valor for correto, você vence.
4. Se for diferente, o jogo informa que você errou.

## Como executar

Você pode abrir o arquivo diretamente no navegador ou utilizar uma extensão como Live Server para visualizar melhor o projeto em um ambiente de desenvolvimento.

## Estrutura do projeto

- `index.html` — estrutura da página do jogo
- `style.css` — estilos visuais da interface
- `app.js` — lógica do jogo
